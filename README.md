# Stream Deck Plugins

A collection of custom plugins for Elgato Stream Deck. Find a plugin below,
download its installer, and add its actions to your keys.

## Available plugins

| Plugin | What it does | Platform |
| --- | --- | --- |
| [PandaDesk](pandadesk/README.md) | Control your PandaDesk height-adjustable desk: move up or down, switch between sitting and standing, recall saved positions, and see the current height. | Windows |
| [Fabricator](fabricator/README.md) | Monitor Minecraft server metrics, control the server, open its admin panel, and send console commands. | Windows, macOS |

Each plugin's guide includes its requirements, setup instructions, and available
actions.

## Install a plugin

1. Open the [downloads page](https://github.com/derDeno/streamdeck-plugins/releases)
   and find the newest release for the plugin you want.
2. Under **Assets**, download the file ending in `.streamDeckPlugin`.
3. Double-click the downloaded file and follow the Stream Deck installation
   prompt.
4. Open Stream Deck, drag the plugin's actions onto your keys, and follow its
   setup guide.

You'll need the Elgato Stream Deck app and a compatible Stream Deck device.
Check the plugin's guide for supported systems and any additional requirements.

## Updates

To update a plugin, download its newer installer from the
[downloads page](https://github.com/derDeno/streamdeck-plugins/releases) and
install it the same way. Plugins are released separately, so look for the
plugin's name when choosing a download.
